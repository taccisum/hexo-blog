### `【六一 & 豌豆思维】营销大数据平台`（2021.08）

**背景**：作为营销中台负责人，经常需要对例如短信发送等运营数据进行周期性计算，以了解过去一个月内公司的运营情况，辅助运营团队进行数据驱动的决策。由于数据量较大，且出于一些内部原因，难以高效地协调到数据部门来完成这些工作，因此最终决定自行搭建营销大数据平台来完成
**难点**：
  - 无实际经验从零到一：进行大量的学习和尝试，同时向有经验的朋友请教
  - 团队成员无 python 经验：采用 Spark SQL 降低门槛
  - 数据分析时不能影响线上业务：MySQL 热备 + Sqoop 定期同步从库至 HDFS 以 ORC 格式存储（由于实时性不能保证，有考虑必要时换成 Flume + HBase 的方案）
**技术栈**：Spark 3.1.2, HDFS, Sqoop + ORC, PySpark, Spark SQL
